# Planning — 任务规划

## 触发条件
- 目标较大、多步骤、需要拆解时；或在执行 scaffold 前先明确计划。

## 流程

### 1. 理解目标
- 明确 goal：最终要达成的可衡量结果
- 识别约束（时间、依赖、资源、兼容）

### 2. 拆解任务（plan）
- 把目标拆成若干可独立完成的任务（task）
- 每项含：做什么、产出物、验收标准
- 标注依赖与并行机会

### 3. 排序与优先级
- 有依赖的先做；无依赖的可并行
- 优先级：核心路径 > 增强 > 打磨

### 4. 里程碑与进度
- 划分里程碑，标注每个任务所属阶段
- 用 `task-tracker` 记录进度

## 输出格式
```
Goal: <明确目标>
Plan:
- [ ] Task1 — 描述 — 产出: xxx — 验收: xxx
- [ ] Task2 ...
Milestones:
- M1: <阶段描述>
依赖/风险: ...
```

## 原则
- **先规划后执行**，不盲目动手
- 计划要**可追踪**（每项可勾选）
- 重大变更时更新 plan，不僵化

## Checklist
- [ ] 目标可衡量
- [ ] 任务可执行、可验收
- [ ] 依赖与并行已识别
- [ ] 用 task-tracker 跟踪
