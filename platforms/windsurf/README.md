# Windsurf 接入方式

- **官方格式**：`.windsurf/rules/*.md`、`.windsurf/rules/.windsurfrules`；AGENTS.md；官方 MCP。
- **本仓库**：根 `AGENTS.md` 已就绪，Windsurf 支持。

## 接入步骤

```bash
mkdir -p .windsurf/rules
# 官方规则文件放 .windsurf/rules/；同时保留根 AGENTS.md 作为统一指令
```

## 说明
Windsurf 支持 AGENTS.md 与 `.windsurf/rules`。以根 `AGENTS.md` 为权威，`.windsurf/rules` 可放场景/目录级规则。
