Pragmatic Guard

拦住 AI 的 5 类坏毛病：重复造轮 · 冗余文件 · 虚假实现 · 过度设计 · 业务不合逻辑

01 为什么需要它

提示词只能约束 AI 的"自觉"，但 AI 常产出 好看却无用 / 假装完成 / 过度抽象 / 不合真实业务 的代码。 Pragmatic Guard 把这件事从"靠提示"下沉为"程序强制校验"——完工时自动扫描，发现问题直接 阻断提交，不通过就过不了门禁。

$ python3 framework/lib/scripts/quality/pragmatic-guard.py --project .
✅ PASS: 0 个问题    exit=0（通过）
❌ FAIL: 4 项 · exit=1（必须整改后重跑）

①

重复造轮

复用检测
②

冗余文件

空文件、占位命名（dummy/stub）、从未被 import 的孤儿文件。

引用扫描
③

虚假实现

pass / TODO / NotImplementedError / 空函数体 / return None 冒充完成。

占位扫描
④

过度设计

为简单需求造工厂、接口、子类、无用配置类。

复杂度信号
⑤

业务不合逻辑

魔法数字、演示字符串、异常被吞、命名不符真实业务。

业务校验

03 整改三步法

1

定位

运行 pragmatic-guard 扫描，拿到具体文件/行号/问题类别。

2

整改

复用已有库 / 删冗余 / 补真实实现 / 去过度抽象 / 命名常量 + 处理异常。

3

复验

重跑直到 exit 0，再进 enforce_active 完工门禁 → 提交。

04 5 类整改对照（坏 vs 好）

① 重复造轮

✗ BAD — 手写 HTTP 客户端
import socket
def http_get(url):
    host, path = url.split("://")[1].split("/",1)
sock = socket.create_connection((host,80))
    sock.send(f"GET /{path}...".encode())
    return sock.recv(1024).decode()
✓ GOOD — 复用现有库
import httpx
def http_get(url):
    return httpx.get(url, timeout=5).text

② 冗余文件

BAD — 一堆没用的文件
src/utils_helper.py        # 空文件
src/placeholder_api.py     # 只有占位符
src/dummy_service.py       # 从未被 import
✗ [redundant] 空文件 · 疑似无用命名 · 可能未被引用
✓ 整改：删除无用文件，新增文件必须被 import/require 引用

③ 虚假实现

✗ BAD — 占位冒充完成
def process_payment(card):
    pass                    # 空函数
    # TODO: 接支付网关

def refund(id):
    raise NotImplementedError
✓ GOOD — 真实现 / 诚实声明
def process_payment(payload):
    return gateway.charge(payload)

def upload(id):
    logger.info("upload 本期不做")
    return False  # 比 raise 诚实

④ 过度设计

✗ BAD — 为读配置造工厂
class ConfigAbstractFactory:
    ...
class JsonConfigReader(ConfigAbstractFactory): ...
class YamlConfigReader(ConfigAbstractFactory): ...
def get_setting(name):
    return JsonConfigReader().read(name)
✓ GOOD — 一个函数搞定（YAGNI）
import json
def get_setting(name, path="config.json"):
    with open(path) as f:
        return json.load(f)[name]

⑤ 业务不合逻辑

✗ BAD — 魔法数/演示串/吞异常
def checkout(items):
    tax = total * 0.0925     # 无命名
    return {"greeting":"hello",...}
    try:
        ...
    except:                # 吞掉异常
✓ GOOD — 常量+真实业务+处理异常
TAX_RATE = 0.0925
def checkout(items):
    tax = round(sum(i.price for i in items)*TAX_RATE, 2)
    try:
        return {"subtotal":..., "tax":tax}
    except ValueError as e:
        raise ValueError(f"无效购物车: {e}")
