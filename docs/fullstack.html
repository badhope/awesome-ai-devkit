工作流

标准化交付流程

每个工作流带明确的质量门禁，阶段产物经验证才进入下一环。

SDLC · 功能开发

需求 → 设计 → 实现 → 测试 → 评审 → 交付

SDLC · 重构

风险识别 → 小步改造 → 行为不变验证 → 回归

SDLC · Bug 修复

复现 → 根因 → 最小修复 → 回归测试

验证循环

写码 → 测试 → 门禁校验 → 反复直至全绿

故障响应

告警 → 定级 → 止损 → 根因 → 复盘

发布清单

版本号 → CHANGELOG → 构建产物 → 回滚预案

新成员接入

环境 → 规范 → 本地验证 → 首个任务
