核心能力

每个场景，都是一支团队

指令润色、安全防御、质量门禁、上下文优化 — 所有场景共享的通用能力。

指令润色

自动将模糊的用户指令转化为结构化提示词，智能推断默认值、补全缺失信息，零配置全自动。

AI 安全防御

Prompt 注入检测、Agent 输出转义、Skill 完整性校验 (SHA-256)、速率限制。覆盖 OWASP Top 10 + AI 专项威胁。

质量工作流

标准化 scaffold 协议驱动多步骤开发，每个阶段有明确的质量门禁和验证机制。变异测试、代码审查、安全扫描内建。

上下文管理

智能上下文压缩、跨会话持久记忆、任务完成后的经验自动提取与复用。所有场景的通用短板。

多模型路由

按任务类型智能选择最优 LLM — 复杂推理用高能力模型、简单改动用低成本模型，自动 fallback。

可组合模块

角色、技能、工作流、钩子各自独立。按需取舍不同场景的模块，构建自己的工作流。

这是一个跨平台的场景化 AI 编程配置仓库。内置通用能力层（11 个通用角色 + 37 个通用技能）与全栈开发团队场景。可按需添加更多领域的场景。MIT 开源。

不是。全栈是内置的第一个场景，作为示例提供。项目架构支持添加更多场景（业务运营、数据工程等），每个场景可以定义自己独立的角色、技能和工作流组合。

任何支持 Expert 插件标准的工具均可使用。查看所用工具的插件安装文档，获取具体的安装命令。

AI Security 包含四层防御：(1) Prompt 注入检测；(2) Agent 输出转义；(3) Skill 签名校验 (SHA-256)；(4) 速率限制。同时覆盖 OWASP Top 10 传统安全。
