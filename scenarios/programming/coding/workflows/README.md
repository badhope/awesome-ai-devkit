# 通用编程场景 — 工作流索引

> Awesome AI DevKit — 通用编码生命周期工作流（跨语言、跨技术栈）。

## 工作流

| 文件 | 说明 | 涉及角色 |
|------|------|---------|
| `coding-lifecycle.md` | 通用编码生命周期：需求 → 方案 → 编码 → 测试 → 审查 → 提交 | Architect, Dev, QA, Reviewer |

## 使用

```bash
# 按编码生命周期推进任意编码任务
awesome-devkit workflow run coding-lifecycle --task "描述任务"
```

> 深度细节（具体技术栈的实现）请参考 `fullstack` 等具体化子场景的工作流。
